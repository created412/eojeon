# 어전 — Astra 6 검토 반영

2026-10-05 로컬 작업본. `gpt-6-astra`의 독립 코드·Chrome 검토를 받아 수정하고, 같은 재현 절차로 다시 확인했다. 공개 배포와 GitHub push는 하지 않았다.

이후 척화비 BGM·복원 음악·공통 소리 조작·스크롤 안내를 추가 수정한 최신 결과는 [2026-10-06 밤사이 점검](overnight-validation-2026-10-06.md)에 있다.

## 실제로 바뀐 동작

| 영역 | 발견한 문제 | 수정 |
|---|---|---|
| 행렬·알현·도주 | 멈춤 화면 뒤에서 이동이나 제한 시간이 진행됨 | 공통 게임 시계로 이동·도주·장면 대기를 계산. Esc, 화면 회전 안내, 다른 탭으로 이동하는 동안 게임 시간이 멈춤 |
| 시간제 미니게임 | 전투·공사·붓쓰기에서 멈춤을 쓸 수 없거나 뒤에서 판이 진행됨 | 정족산성·광성보·경복궁 공사·붓쓰기에도 멈춤 적용. 타이머·입력·결과 화면 대기를 함께 정지 |
| 자막 | 행렬을 멈춰도 독백이 다음 줄로 바뀌거나 가마 자막이 사라짐 | 독백 순서와 배너 수명, 가마 자막 예약을 같은 게임 시계에 연결 |
| 키보드·터치 | 멈춤 중 Tab 초점이 뒤의 게임으로 빠짐. 회전 안내 뒤에도 발생 | 멈춤 안에서 초점 순환·복원. 시간제 미니게임에서도 위쪽 멈춤 단추 사용 가능 |
| 저장 기록 | 처음부터 시작을 한 번 누르면 저장 기록을 지움 | 오프닝과 멈춤 메뉴 모두 기존 기록 삭제를 별도로 확인. 취소하면 기록 보존 |
| 3D 렌더링 | 불투명 미니게임 아래 보이지 않는 궁궐을 매 프레임 다시 그림 | 전투·공사·저울·가마·붓쓰기 등 불투명 전면 판에서는 궁궐 그리기를 쉼. 반투명 대화에서는 계속 그림 |

영상은 V23 마지막 49~55초를 반복한다. 소리는 별도 연속 사운드트랙으로 이어지고 「영상을 불러오고 있습니다」는 표시하지 않는다. 새 게임은 오른쪽 아래 「게임 시작」으로 시작하며, 유효한 저장이 있으면 삭제 확인을 거친다. 이전 수정 내역과 전체 장면 확인은 [영상 진입·최종 점검](final-validation-2026-10-05.md)을 참고한다.

## 사료와 학습 피드백

사료 카드만 고치지 않고 연결된 밑줄 문제, 따져 읽기, 파발, 훈령, 사초 퀴즈와 해설도 함께 맞췄다.

- **운요호 사건:** 조선이 처음 발포했다는 문장만으로 시작하던 설명을 접근 → 조선의 경고 사격 → 일본의 포격·약탈 순서로 수정했다. 교과서·사건 경과를 요약한 글을 원본 장계처럼 보이게 하지 않도록 출처와 재구성 등급을 바로잡았다. 우리역사넷의 「운요호 사건」 중 사건 경과를 설명하는 4절을 대조했으며, 3절의 사후 보고서 서술과 구별했다. [국사편찬위원회 우리역사넷](https://contents.history.go.kr/mobile/kc/view.do?levelId=kc_i402530)
- **영남 만인소:** 원문이 경계하는 나라를 일본으로 잘못 적은 부분을 러시아로 수정했다. 미국과의 연대를 둘러싼 비판이라는 문맥에 맞춰 풀이도 고쳤다. [국사편찬위원회 우리역사넷](https://contents.history.go.kr/front/hm/view.do?levelId=hm_116_0080)
- **벨로네의 편지:** 출처와 맞지 않는 인용을 교과서에 실린 정복 예고·조선 왕위 결정권 주장 부분으로 바꿨다. 퀴즈가 새 발췌문에 없는 내용을 요구하지 않도록 질문도 맞췄다. [국사편찬위원회 우리역사넷](https://contents.history.go.kr/front/hm/print.do?levelId=hm_114_0040)

## 재현 검증

- 행렬을 9초 멈춘 동안 위치·자막·렌더 프레임이 같고, 재개 후 다시 진행한다.
- 실제 가마의 첫 자막 「발이 걷힌다.」에서 5초 멈춰도 자막·위치·렌더 프레임이 같다. 재개 2.5초 뒤 다음 자막과 동작이 진행한다.
- 도주를 4초 멈춘 동안 남은 시간은 26초로 유지되고, 재개 1.5초 뒤 24초로 진행한다.
- 조작권을 빼앗긴 장면을 13초 멈춰도 진행 단추가 미리 나타나지 않는다. 재개 후 실제 게임 시간이 흘러야 나타난다.
- 붓쓰기를 4초 멈춘 동안 남은 시간·먹의 양·캔버스가 같고, 재개 후 다시 진행한다.
- 정족산성·광성보·공사에서 멈춤 중 상태와 입력이 고정되고, 재개 후 시간이 흐른다. 불투명 판 뒤 궁궐의 렌더 프레임은 증가하지 않는다.
- 멈춤 안에서 Tab 14회 순환, 가로·세로 회전 후 초점 복원, 새 게임 삭제 확인의 취소·확정을 검사한다.

회귀 검사는 `tests/ui/game-quality-browser.test.js`, `tests/core/game-time.test.js`, `tests/systems/voice.test.js`, `tests/data/historical-corrections.test.js`, `tests/ui/prologue-browser.test.js`에 있다. [Astra의 실제 Chrome 재검토 증거](qa/2026-10-05/astra-final-report.json)에는 최종 수정으로 확인한 행렬·도주·조작권 제한·붓쓰기·가마 결과를 모았다.

최종 전체 검사: `EOJEON_TEST_EXISTING_BUILD=1 npx vitest run --fileParallelism=false` → **129파일·2,626개 모두 통과**, 162.51초. 첫 병렬 실행에서는 기능 테스트 2,626개가 통과했으나 `today-browser`의 Chrome 종료 훅이 10초를 넘겼다. 테스트를 생략하거나 시간 제한을 늘리지 않고 전체 순차 실행으로 다시 통과했다. 전체 로그는 로컬 `_tools/checks/astra-final-serial-vitest.log`에 보관했다.

최종 HTML은 13,575,584바이트(13,257 KiB 표시)로 13 MiB 상한 이내이며, 뿌리와 `dist` 파일의 SHA-256이 모두 `40a1fbaf13482f45da58055a98c26d28887708629efc3e4739625a2b1e983449`이다. 검사 전용 전역 변수를 포함하지 않는다. V23 MP4와 연속 M4A도 원본 자산과 `dist` 복사본이 각각 같다. 저장 VERSION 7과 5막 76장면 순서는 유지했다.

Windows Chrome에서 확인했다. 실제 태블릿·Safari에서의 손 조작, 학생 수업 관찰, 장시간 플레이의 평균 FPS를 측정한 결과는 아니다. 보이지 않는 3D 그리기를 줄였다는 관찰을 전체 게임의 특정 FPS 상승률로 해석하지 않는다.
