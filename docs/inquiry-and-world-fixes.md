# 탐구와 이동 개선 작업

요청: 서사·탐구 피드백, 벽 충돌, 재구성 인물 배경 제거, 강화도·광성보 상호작용 지도, 척화비 완료 판정.

설계: 사료를 받은 화면에서 학생이 먼저 근거를 선택하고 해석을 쓴 뒤 설명을 비교한다. 서계는 원문에서 확인한 용어를 발췌해 皇·勅을 동그라미 표시하고, 강화도 조약 제1·7·10관은 문구·명분·일본의 이익·조선의 권한을 연결한다. 특정 단어를 답에 썼다고 정답 처리하지 않으며, 작성 내용을 보존한다. 기존 막·비트 순서와 저장 좌표는 유지한다.

충돌 원인: 화면의 건물은 논리적 방 크기의 72%인데 이동은 100% 방 경계만 검사한다. 몸의 반경과 한 프레임 사이의 경로도 없다. 렌더링과 충돌이 같은 건물 치수를 쓰도록 통일하고, 실제 벽·기둥과 원형 몸체 충돌을 작은 이동 단계마다 검사한다. NPC 위치도 동일한 기준으로 보정한다.

지도: Natural Earth 공개 해안선 자료를 경기만 범위로 잘라 파일에 포함한다. 확대해도 선명한 해상도로 그리며, 도착한 장계만 해당 지점에 접근 가능한 버튼으로 배치한다. hover·키보드 focus·click·touch가 동일한 보고서를 연다. 광성보와 초지진에도 같은 규칙을 적용한다.

척화비: 현재 55%만 따라 쓰면 자동 진행하고 다음 버튼으로 무조건 건너뛸 수 있다. 완료 기준을 높이고, 글자 각 부분을 확인하며, 자동 진행을 없앤다. 완료한 뒤에만 다음 버튼을 누른다. 안내선은 번들에 포함해 기기 글꼴 부재를 자동 통과로 처리하지 않는다.

검증 계획: 얇은 벽·긴 프레임·대각 이동·문 통과·NPC 위치, 미완성 글자와 빈 안내선, 사료 활동 입력 및 복원, 지도 hover/focus/touch, 화면 크기별 브라우저 점검. 최종적으로 루트와 dist의 어전.html을 다시 빌드한다.

## 구현·검증 결과 (2026-09-12)

- 서계와 강화도 조약 제1·7·10관에 근거 표시·서술·비교·보완 활동을 적용했다. 작성 내용은 기기에 저장되며 사초함에서 재열람하고 ‘내 기록 복사’로 가져갈 수 있다.
- 렌더링과 같은 72% 건물 치수로 벽·기둥·회랑 충돌을 계산한다. 몸의 반경을 반영하고 긴 프레임도 작은 이동 구간으로 나누어 검사한다. NPC의 기본 위치와 연출 중 위치도 같은 장애물 기준으로 보정한다. 문 건물의 중앙 통로를 앞뒤로 열었다.
- 재구성 인물의 남색 사각 패널·테두리를 제거하고 투명 배경과 그림자를 적용했다. 실제 역사 사진은 사진 자체와 출처를 유지한다.
- 강화도·광성보·초지진 장계 지도 3개에 현대 해안선 자료와 확대된 해상도를 적용했다. 도착한 장계의 위치만 표시하며 지명과 목록 모두 hover·focus·click으로 보고를 연다. 작은 화면에서는 세로로 배치한다.
- 척화비는 안내선 92% 이상과 글자 각 영역의 획을 확인한다. 미완성 상태의 다음 단추는 잠기며 자동 진행하지 않는다. 12자를 모두 완성하고 각각 다음 단추를 눌러야 마친다. 동일한 판정을 ‘日使來衛’에도 적용한다.
- `npm run build`: 루트와 dist의 어전.html 생성, 약 8,021 KB.
- `npm test`: 64개 파일, 1,204개 검사 통과.
- `node tools/inquiry-world-check.cjs`: 네 탐구, 지도 3개, 실제 포인터로 척화비 12자 완료, 모바일 크기 3종, 투명 인물 배경 검사. 실제 배포 HTML에서 입력·새로고침·복원과 이어하기 지점 보존도 확인했다. 브라우저 오류·외부 요청 0건. 화면 기록은 `.superpowers/inquiry-world-qa/`.
- `node tools/historical-media-check.cjs`: 사료 카드 25개, 인물 17명, 자료 이미지 21개 및 실제 게임의 사진 확대·대화 유지 확인. 브라우저 오류·외부 요청 0건.
- `node tools/visual-check.cjs`: 5개 막의 회의·탐색·긴박한 장면과 마지막 화면 등 15개 장면 검사. 브라우저 오류·외부 요청 0건.

사진 확대창 검사는 Esc 직후의 순간적인 DOM 개수 대신 실제 닫힘 이벤트 완료를 기다리도록 수정했다. 기능의 통과 기준을 낮춘 것은 아니다.

## 범위와 남는 한계

서사에 대한 구체적인 피드백과 후속 장면 설계는 [story-inquiry-feedback.md](story-inquiry-feedback.md)에 정리했다. 5개 막의 모든 대사를 전면 교체한 작업은 아니다. 지도는 현대 Natural Earth 해안선에 기반한 위치 안내도이며 19세기 지형 복원이 아니다. 붓 판정은 획이 그려진 범위를 확인하고 정식 서예의 필순·자형 품질까지 채점하지 않는다. 전용 사진이 확인되지 않은 인물은 재구성임을 표시한다.
