# 대화 인물과 사료 이미지

2026-09-11 적용. 실제 게임의 대화창 오른쪽에 사진·초상을 표시하고, 사료 카드 25개와 주요 사건 지문에 원본 또는 관련 이미지를 연결했습니다. 원본 자료 21개를 HTML 안에 포함하여 파일만 열어도 표시됩니다. 그림을 누르면 확대하고, Esc 또는 닫기 버튼으로 돌아옵니다. 원본 출처 링크를 눌렀을 때만 인터넷을 사용합니다.

- 흥선대원군: 양시태 조상관의 1883년 사진. 사진의 연도를 화면에 표시합니다.
- 최익현: 채용신이 그린 초상. 업로드 날짜를 제작 연도로 사용하지 않습니다.
- 신헌: 작자 미상의 전래 초상.
- 실명이 없는 역할 인물: 기존 게임 이미지에 ‘역할 재구성’ 표시.
- 홍재학: 확인된 초상을 확보하지 못해 재구성임을 표시합니다. 다른 실존 인물의 사진으로 대신하지 않습니다.
- 당백전: ‘當百’ 표기가 있는 앞·뒷면 실물 이미지.
- 척화비, 조일수호조규, 제물포 조약 제4·5관, 조선책략: 유물 사진 또는 문서 이미지.
- 원납전·상소·장계 등: 해당 지문과 관련된 장소·인물·문헌 이미지. 지문의 원본 자료인지 관련 자료인지 설명에 구분합니다.

사진을 AI로 복원하거나 얼굴을 바꾸지 않았습니다. 내려받은 이미지는 `assets/historical/originals/`에 보존하고, 비율을 유지한 크기 조정과 WebP 압축본을 게임에 사용합니다. 조선책략은 국립중앙도서관 필사본을 제공하는 Commons의 표지 미리보기 이미지를 사용합니다. 자료별 제공자·출처·라이선스·변환 내역은 `assets/historical/manifest.json`, 조회 당시 원본 메타데이터는 `assets/historical/commons-metadata.json`에 기록했습니다. CC BY-SA 이미지는 해당 이미지의 동일 라이선스를 유지합니다. 함평 척화비는 문화재청의 공공누리 제1유형 출처를 표시했습니다.

`node tools/pack-historical-media.mjs`로 보존된 자료를 다시 묶고, `npm run build`로 루트와 dist의 어전.html을 갱신합니다. 기존 다운로드가 있으면 이미지 포장 과정도 오프라인입니다. 출처 재조회는 별도의 `node tools/collect-historical-media.mjs`로 실행합니다.

검증: 자동 검사 1,195개 통과. `node tools/historical-media-check.cjs`에서 사료 25개·인물 17명 이미지 로드, 우측 배치, 확대/닫기, 지문 진행 유지, 320·390·844px 화면, 실제 배포 HTML의 첫 알현을 확인했습니다. 브라우저 오류와 자동 외부 요청은 0건입니다. 검증 화면은 `.superpowers/historical-media-qa/`에 저장합니다.
