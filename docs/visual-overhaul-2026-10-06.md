# 어전: 그림 선택과 궁궐 생활 개편

사용자가 보낸 화면 피드백을 바탕으로 로컬 게임을 수정했다. 배포·push는 하지 않았다.

## 적용한 변경

- 정책 4판의 선택지 12장과 실제 역사 4장, 문서 선택 46장과 낱말 10장: Higgsfield 생성 그림 총 72장. 각 보기의 뜻을 표현하며, 정오 여부로 그림을 강조하지 않는다. 선택의 득실과 실제 역사를 단계별로 분리한다.
- 대화는 큰 고딕 본문, 명확한 다음 버튼, 투명 인물로 개편했다. 긴 대사는 본문만 스크롤한다. 흥선대원군은 다른 실제 사진으로 교체했다. AI 배경 제거 편집 사실을 표시하고 원본 자료는 별도 확대창에서 보존한다.
- 안내는 목표·조작 중심으로 줄이고, 긴 역사 설명과 출처는 펼칠 수 있게 했다. 막 종료 기록을 사료 그림 카드와 여정 페이지로 바꿨다.
- 인물 머리 위 이름·목적·화살표를 없앴다. 물길·연못은 충돌 영역으로 처리하고 다리와 누각 접근은 유지했다.
- 궁인 수와 생활 동선을 늘렸다. 창덕궁·경복궁에 궁녀를 각각 두 명 배치했다. 궁녀 원화는 Higgsfield로 생성했으나 3D 생성 도구가 노출되지 않아 실제 메시·관절을 코드로 구현했다. 평면 스프라이트가 아니다.
- 숨은 살림 물건 세 종류와 발견 모음 보상을 추가했다. 물건과 사연은 모두 재구성으로 표시하며 사료·필수 진행과 구분한다. 사초함에서 모음을 다시 볼 수 있다.
- 정족산성·광성보에 Higgsfield 전장 배경과 움직이는 병사·함선·연기·물보라를 연결했다. 정족산성 승리 조건과 광성보 함락의 역사적 구조는 유지한다.
- 척화비 國 윗변 누락은 안내점 샘플링 오류였다. 2×2 영역의 모든 픽셀을 검사하도록 바꾸어 얇은 획도 보존한다.
- 친정 직후 독백에도 현재 막 BGM을 연결했다. 오프닝의 마지막 영상 반복과 독립 연속 음악은 유지한다.
- 사료 밑줄·따져 읽기·문서 뜯어읽기·서계·저울 확인 문제를 잘못 짚으면 현재 막의 도입부터 다시 시작한다. 새 막 시작 상태를 깊은 복사로 저장하고 앞 막의 기록을 보존한다. 구형 VERSION 7 저장은 막 소속 정보로 시작 상태를 복원한다. 정오 없는 정책 판단·회고에는 적용하지 않는다.

## 검증 범위

최종 빌드 뒤 `EOJEON_TEST_EXISTING_BUILD=1 npx vitest run --fileParallelism=false`: **136파일·2,687개 통과**. 로그는 `docs/qa/2026-10-06/visual-overhaul/tests.txt`.

HTML은 16,181,832바이트이며 루트와 dist가 동일하다. SHA-256: `beceeecb91fdc3e261ce150412be44a2b654d9e9215a600c9b256b877a1fa053`.

최종 배포용 HTML을 실제 Chrome으로 76개 저장 위치에서 열었다. **진입 실패 0, JavaScript 오류 0, 가로 넘침 0**. `docs/qa/2026-10-06/visual-overhaul/scene-audit.json`은 각 장면의 표시 결과다. 이는 모든 저장 위치의 진입 검사이며, 사람의 처음부터 끝까지 연속 플레이를 뜻하지 않는다. 전체 장면 캡처는 로컬 `_tools/checks/visual-overhaul-audit/`에 있다.

- 실제 Chrome에서 그림 정책판 4종 × 1366×768·844×390·390×844, 문서 4판의 모든 문항을 진행했다.
- 대화 세 화면 크기에서 글씨·버튼 겹침, 긴 본문 스크롤, E/클릭 진행, 원본 보기와 복귀를 확인했다.
- 두 전투는 데스크톱·가로 화면의 배치, 멈춤 중 정지, 승리/함락 후 완료까지 확인했다.
- 궁녀의 앞·옆·뒤, 보행·궁 교체·정리, 숨은 물건의 실제 충돌·문을 통한 접근, 보상 저장·재열람을 검사했다.
- 새 막 재시작을 다섯 막에서 실제 실행하고 앞 막 기록, 오디오, 화면·입력 중복, 저장 덮어쓰기 여부를 확인했다. Astra 6와 독립 코드 검토에서도 확정 오류가 발견되지 않았다.

주요 증거는 `docs/qa/2026-10-06/visual-overhaul/`, `guidance/`, `discoveries/`에 보관했다. 이미지 원본·생성 출처는 각 assets 폴더의 README/manifest에 있다.

실기기 Safari·태블릿 및 학생의 처음부터 끝까지 연속 플레이, 수업 시간에 맞는 체감 난도는 아직 확인하지 않았다. 사료 오류 때 막 전체를 다시 시작하는 규칙은 사용자의 요청대로 적용했으며, 수업에서 반복 부담을 확인할 필요가 있다.

그림·초상·메시가 늘어 오프라인 HTML 크기 한도를 기존 13MiB에서 18MiB로 조정했다. 음악과 게임 자산은 내장되며, 오프닝 영상·연속 음원은 기존 로컬 동반 파일을 사용한다.
