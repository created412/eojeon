# 어전 — 영상 진입과 최종 점검

2026-10-05, 로컬 작업본. 공개 배포·GitHub push는 하지 않았다.

아래는 영상 연결 직후의 1차 점검 기록이다. 이후 게임 시간·미니게임·접근성·저장 보호·사료를 추가 수정한 최신 결과는 [Astra 6 검토 반영](astra-quality-review-2026-10-05.md)에 있다.

## 첫 화면과 음악

게임을 열면 제목 메뉴 없이 V23 55초 영상부터 재생한다. 49초부터 오른쪽 아래 「게임 시작」이 나타나며 누르기 전까지 49~55초 구간을 반복한다. 버튼을 누르면 1막 도입과 1막 BGM으로 이어진다. 건너뛰기는 마지막 반복 구간으로 이동한다. 유효한 저장이 있을 때의 이어하기는 저장 장면을 바로 연다.

소리 있는 자동 재생이 차단되면 「소리와 함께 재생」 단추를 표시하고 기다린다. 자동으로 무음 재생하지 않는다. 사용자가 직접 저장한 음소거 설정은 유지한다. 영상이 없으면 오류 안내와 게임 시작 단추를 표시한다. 자동으로 저장을 지우거나 게임을 시작하지 않는다.

V23 영상은 원본 그대로이며 원래 대사·음악을 포함한 연속 사운드트랙을 별도로 재생한다. 영상이 반복되어도 음악은 다음 부분으로 진행한다. 로딩 문구는 제거했다. 게임 시작 때 오프닝 음악이 1.4초간 작아진다. 앞선 Suno 개편의 오프닝 원곡과 장면별 새 BGM을 유지한다. 영상과 마지막 구간 반복 중에는 게임 BGM이 겹쳐 나오지 않는다.

## 발견하여 고친 문제

| 문제 | 수정 |
|---|---|
| 사료를 읽는 중 E가 가까운 물건을 열어 사료를 덮어씀 | 열린 사료의 닫기 판정을 우선한다. 밑줄·따져 읽기 조건은 그대로 적용한다 |
| 받은 사료를 읽다가 새로고침하면 남은 읽기를 건너뜀 | 읽는 카드 묶음과 남은 순서를 저장하고 이어하기에서 복원한다. 복원 직후 E로 닫기도 정상 작동한다 |
| 844×390 가로 화면에서 급료 가마 쟁반이 2px로 줄어듦 | 세로 축소를 막고 짧은 화면에 맞게 쟁반 크기를 조정한다 |
| Windows에서 HTML 쓰기가 막히면 기존 결과 파일이 빈 파일로 남을 수 있음 | 임시 파일에 완성한 뒤 교체하며 두 출력의 완료·실패를 모두 기다린다 |
| 이전 판 저장 안내가 없어진 「처음부터」 단추를 가리킴 | 현재 「게임 시작」 단추 이름으로 맞춘다 |

장면 순서와 저장 판은 VERSION 7을 유지했다. 새 카드 복원 필드는 선택 사항이라 기존 판 7 저장을 읽을 수 있다.

## 검증의 한계

이번 조작 검사는 Windows Chrome과 Playwright의 터치 모사로 했다. 실제 태블릿·Safari에서의 손 조작과 성능을 확인한 것은 아니다. 76개 장면 검사는 저장 위치별 진입 확인이며, 사람이 처음부터 끝까지 연속으로 수업하듯 완주한 검사는 아니다. 완주 시간과 학생 반응은 아직 측정하지 않았다.

스크린샷과 세부 조작 로그는 로컬 `_tools/checks/`에 있다. 영상·음악 원본과 출처는 각각 [영상 안내](../assets/video/README.md), [음악 안내](../assets/bgm/README.md)를 따른다.
