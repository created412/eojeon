# 「어전」 스토리·역사 탐구 피드백

## 핵심 진단

현재 서사는 사건의 결론을 먼저 설명한 뒤 학생에게 다음 화면을 넘기게 하는 비중이 크다. 고종의 행동이 역사적으로 제한되었다는 설정 자체보다, 그 상태에서 학생이 할 수 있는 역사적 사고가 부족한 것이 답답함의 원인이다. 왕을 움직이지 못해도 문서의 표현을 의심하고, 보고를 비교하고, 자기 해석을 수정할 수 있어야 한다.

사진만 추가해서는 해결되지 않는다. 사진과 원문이 질문을 해결하는 증거가 되어야 한다. 읽은 사료의 수와 해석의 깊이도 구별해야 한다.

## 이번에 게임에 적용한 탐구

| 자료 | 학생이 먼저 하는 일 | 작성 뒤에 열리는 비교 |
| --- | --- | --- |
| 서계 | 皇·勅에 동그라미를 표시하고 외교적으로 문제가 된 까닭을 설명한다. | 일본의 새 정부 성립 통보와 조선의 교린 격식·위계 인식을 함께 살핀다. 朝臣·인장 변경도 관련되었음을 보완한다. |
| 강화도 조약 제1관 | ‘자주’ 또는 ‘평등’을 고르고 명분과 일본의 외교적 이익을 구분한다. | 청의 관여를 배제하려는 의도와, 문구만으로 실제 청의 영향력이 사라지지는 않는다는 점을 비교한다. |
| 제7관 | 측량하는 주체와 허용된 행동을 표시한다. | 항해 안전이라는 명분과 해안 정보의 군사적 활용 가능성을 구분한다. |
| 제10관 | 재판의 주체가 드러나는 구절을 표시하고 양국의 권한을 비교한다. | 영사 재판권과 조선의 사법권 제한을 연결한다. |

각 활동은 ‘질문 → 근거 표시 → 내 해석 → 해설과 비교 → 생각 보완’ 순서다. 단서는 두 단계로 제공한다. 비교 전에는 기존 카드의 결론 설명을 숨긴다. 특정 단어를 답안에 썼다고 정답 처리하지 않는다. 근거 표시와 최소 작성 여부를 확인하며, 서술 내용의 타당성을 자동 채점하지 않는다.

최초 해석과 비교 뒤 보완을 따로 보존한다. 사초함에서 이미 읽은 문서를 다시 열 수 있고, ‘내 기록 복사’에 근거·해석·보완 내용이 함께 나온다. 입력 중에도 저장하되 게임의 안전한 이어하기 지점은 유지한다.

서계 화면의 한자는 확인한 원문 용어의 발췌이며, 원문 전문의 사진이나 이어진 완전한 문장으로 제시하지 않는다. 강화도 조약은 기존 게임이 다루던 핵심 3개 관에 탐구를 적용했다. 12개 관 전체에 활동을 만든 것은 아니다.

## 전체 내러티브의 후속 개편 우선순위

1. **협상 전후의 지식을 분리한다.** 현재 3막에는 신헌이 ‘맺은 조약문’을 건네는 설정과 협상에 보낼 훈령 활동이 가까이 섞여 있다. 협상 전에는 당시 확보한 자료로 지시문을 쓰고, 체결 뒤 조약문을 받아 자신의 예상과 비교하도록 분리해야 한다. 학생이 미래 조항을 이미 아는 상태로 과거의 협상 지시를 쓰지 않도록 하는 것이 우선이다.
2. **선택의 보상을 해석의 변화로 만든다.** 다른 선택을 했다고 ‘실제로는…’만 보여주면 선택이 무의미해진다. 실제 결과를 보여주되, 제시한 근거가 어떤 제약을 발견했고 무엇을 놓쳤는지 되돌아보게 해야 한다. 역사가 마음대로 바뀌는 보상 없이도 탐구의 성취를 줄 수 있다.
3. **대화마다 해결할 질문을 하나 둔다.** 사건 설명 세 장을 연속으로 넘기기보다 첫 인물은 문제를 제기하고 다음 인물은 판단을 어렵게 하는 자료를 가져오게 한다. ‘일본 문서 도착 → 어떤 글자가 문제인가 → 왜 양쪽 해석이 갈리는가’처럼 연결한다.
4. **사료 해석 시간과 이동 시간을 경쟁시키지 않는다.** 오래 읽는 학생이 시간이 부족해서 핵심 탐구를 놓치는 구조는 피한다. 긴박한 탈출 장면의 시간 제한과 사료 해석 시간은 구분할 필요가 있다.

| 막 | 중심 질문 | 다음 장면으로 가져갈 산출물 제안 |
| --- | --- | --- |
| 즉위 | 중건 비용은 누가 부담하는가? | 당백전의 정해진 교환 가치와 실제 가치가 다를 때 피해가 누구에게 가는지 설명 |
| 양요 | 지연된 장계로 어디까지 확신할 수 있는가? | 거점 두 곳과 보고 시점을 근거로 한 판단 |
| 친정 | 평등을 말하는 조약이 어떻게 불평등하게 작동하는가? | 제1·7·10관의 명분·권한·위험 비교 |
| 임오군란 | 다른 집단은 같은 사건의 책임을 어떻게 설명하는가? | 공통 사실과 서로 다른 주장의 구분 |
| 갑신정변 | 사건 당사자의 회고를 어디까지 믿을 수 있는가? | 작성 시점·처지·교차 검증 자료에 근거한 신뢰도 판단 |

위 표의 전체 막 활동은 후속 설계 제안이다. 이번에는 앞 표의 네 탐구, 지도 장계 열람, 기록 보존과 화면·이동 오류 수정을 구현했다. 5개 막의 사건 배열·대사를 전면 교체하지는 않았다.
