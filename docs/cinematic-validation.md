# 개편판 검증 기록

2026-09-11 기준 `npm.cmd test`를 실행해 Vitest 60개 파일, 1,160개 테스트가 통과했습니다. 이 명령은 `dist/어전.html` 단일 파일도 다시 생성합니다.

Chrome 헤드리스 실행 점검(`tools/visual-check.cjs`)에서는 다음을 확인했습니다.

- 1막 즉위부터 5막 갑신정변까지 각 막의 회의와 탐색 화면
- 친정의 경복궁 화재, 임오군란, 갑신정변의 제한 시간 장면 및 시간 종료 후 위기 HUD 정리
- 회의 선택지 제출과 성찰문 제출, 사초함 열기·닫기, 마지막 기록 화면
- 390×844 터치 화면과 `prefers-reduced-motion` 설정에서 이동·버튼·회의 선택지
- 페이지 오류 0건, 외부 HTTP 요청 0건
