# 어전: 영화 같은 사실풍 궁궐과 UI

실행 파일: 작업 폴더의 `어전.html`. `npm run build`는 이 파일과 `dist/어전.html`을 동시에 갱신한다. 브라우저에서 파일을 직접 열 수 있으며 서버나 외부 리소스가 필요하지 않다.

## 바뀐 화면

- 실제 게임의 궁궐 전경을 보여 주는 시작 화면, 다섯 막의 연도와 제목.
- 짙은 회청색·오래된 황동색 UI, 현재 임무, 보고 여유, 읽은 사료 수, 현재 막 표시.
- 담장·현판·기둥 초석·중층 정전 지붕·소나무 숲·주변 지형과 조명.
- 실제 인물 비례의 고종과 네 종류의 신하 모델. 나이별 키, 관모와 의복 텍스처, 뼈대 기반 걷기·달리기 동작. 의복의 자체 발광을 제거하고 장면 조명을 받도록 조정했다.
- 낮고 가까워진 카메라, 좌우 회전 및 시점 초기화 버튼. 앞을 가리는 문루는 마루를 남기고 구조물을 함께 숨긴다.
- 박석·기와·목재의 질감과 요철, 마모된 단청, 세분화한 소나무 수관과 입체 산 능선. 게임 내 재질과 조명으로 사실적인 분위기를 구성한다.
- 태블릿과 작은 화면에 맞춘 안내도와 조작 버튼.

역사 시나리오, 사료 원문, 선택·성찰 기록, 저장 형식은 기존 구조를 사용한다. 공간과 인물의 외형은 학습용 재구성이다.

## 조작

WASD/방향키 이동, Shift 달리기, E 대화·상호작용, Q 사초함, Esc 멈춤·저장.
마우스 우클릭 드래그로 회전하고 휠로 확대·축소한다. 오른쪽 위의 회전 버튼과 나침반 버튼으로 회전·시점 초기화를 할 수 있다. 터치 기기는 바닥을 짚어 이동한다.

## 검증

`npm test -- --reporter=dot`: 전체 시나리오·입력·저장·렌더링 및 빌드 회귀 검사.

`node tools/visual-check.cjs`: 5막 회의·탐색·위기·엔딩, 사초함, 모바일 성찰 입력, 브라우저 오류와 외부 요청 검사.

`node tools/metaverse-preview.cjs 어전.html`: 실제 실행 파일의 시작 화면·캐릭터·회전·모바일 화면, 터치 시점 전환, 좁은 화면과 가로 화면 시작 버튼 검사. 캡처는 `.superpowers/metaverse-qa/`에 저장한다.

작업 직전 실행 파일과 주요 수정 파일의 사본은 `.superpowers/metaverse-before/`에 보관했다.
앞서 만든 미니어처풍 실행 파일은 `.superpowers/miniature-version/어전.html`에 따로 보관했다.
