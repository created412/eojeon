# 안내 화면과 척화비 점검 — 2026-10-06

- 척화비 시작 안내: 목표·조작·시작 단추를 먼저 제시. 원래 지문은 배경 펼치기에 모두 보존하고 출처는 상시 표시한다.
- 일반 지문: 두 문단씩 넘기며 이전 페이지로 돌아갈 수 있다. 한자 풀이·대조 자료·뒤따르는 문장·출처를 보존한다.
- 막의 여정: 세 걸음씩 제시하고 상세 설명은 각 걸음에서 펼친다.
- 막 종료: 읽은 문서의 실제 관련 자료를 그림 카드로 제시한다. 한 화면에 세 장(좁은 세로 화면은 한 장), 학생의 긴 기록은 카드에서 펼친다. 재구성 그림과 역사 자료를 구분하고 그림을 확대하면 원래 출처·관계 설명이 열린다.
- 붓 화면: 조작 한 줄을 먼저 제시하고 비문 뜻·출처를 펼쳐 읽게 한다. 가로 태블릿에서는 쓰는 판과 조작을 좌우로 나누어 다음 단추까지 화면 안에 둔다.
- 國 안내선: 기존 생성기가 96px 글꼴에서 홀수 x·y 좌표만 검사하여 얇은 가로획을 누락했다. 2×2칸 전체에서 가장 짙은 실제 획을 뽑도록 고쳐 바깥 윗변·안쪽 가로획을 복구했다. 안내점의 명암도 높였다. 기존 자산 생성기도 새 생성기를 호출하므로 재생성 때 되돌아가지 않는다.

검증: 담당 8개 시험 파일 206개 통과. `today-browser.test.js` 7개 통과. 마지막 명암 변경 뒤 붓 관련 79개 재검증 통과.

Chrome headless 소스 UI fixture를 1366×768·844×390에서 열어 목표 안내, 일반 지문, 막 종료, 막 여정, 붓 화면을 확인했다. 10개 화면의 JS 오류 0·가로 넘침 0. 지문 앞뒤 넘기기·원문 보존, 그림 카드 다음 페이지, 國 안내선 그리기→다음 글자 활성→붓 놓기까지 확인했다. 화면 자료는 `docs/qa/2026-10-06/guidance/`, 재현 스크립트는 로컬 `_tools/checks/guidance-visual.mjs`다.

이 기록은 개별 UI와 해당 시험 결과다. 통합 빌드·전체 저장 위치 검사는 별도로 진행하며, Safari·태블릿 실기기는 확인하지 않았다.

## 궁살림 선택 발견 추가

무명 수건·다 쓴 붓·남은 천 조각을 창덕궁과 경복궁의 생활 공간에 입체 물건으로 추가했다. 물건과 짧은 사연은 모두 재구성임을 표시한다. 세 물건을 찾으면 「궁을 움직이는 손길」 기념 장면이 열리고, 저장 후에도 사초함의 별도 발견 모음에서 다시 볼 수 있다. 실제 사료·필수 활동·낮 예산·비트 수는 바꾸지 않는다. NPC 머리 위 표식이나 자동 이동도 추가하지 않는다.

두 궁의 발견 위치 여섯 곳이 벽·기둥·물과 겹치지 않는지, 스폰에서 문을 통과해 접근 가능한지 0.5m 격자 탐색으로 검사했다. 발견 판정과 입체 물건의 좌표 일치, 중복 보상 방지, 저장 복원, 첫 발견 전 모음 숨김도 확인했다. 관련 4파일 33개 시험 통과. Chrome 1366×768·844×390에서 입체 물건, 보상 카드, 사초함의 보상 재열람·복귀를 확인했으며 JS 오류 0·가로 넘침 0이었다. 캡처는 `docs/qa/2026-10-06/discoveries/`, 재현 스크립트는 로컬 `_tools/checks/palace-discoveries-visual.mjs`다. 입체 물건 캡처는 개별 물건을 모아 확인하는 fixture이며, 실제 궁 안의 카메라 동선 검사를 대신하지 않는다.
