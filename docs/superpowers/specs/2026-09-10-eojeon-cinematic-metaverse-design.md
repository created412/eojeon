# 「어전」 시네마틱 메타버스 개편 설계서

## 목표

1863년 고종 즉위부터 1884년 갑신정변까지의 다섯 막 캠페인과 사료 기반 판단 구조를 보존하고, 이를 교실에서 즉시 실행되는 영화적 3D 역사 체험으로 전면 재구성한다.

## 유지할 사실 기반 구조

- 다섯 막의 시간 흐름, 역사적 사건, 사료 카드, 선택 조건, 실제 역사 결과를 유지한다.
- 플레이어의 선택은 역사 자체를 바꾸지 않는다. 바뀌는 것은 고종이 사건을 맞을 때 가진 정보와 기록이다.
- 사료의 출처와 `사료`·`교과서`·`재구성` 등급을 유지한다.
- 단일 HTML 배포와 키보드·터치 입력, 저사양 교실 PC 실행을 유지한다.

## 경험 원칙

### 궁궐은 배경이 아니라 통치 공간이다

탐색 장면은 3인칭 오버숄더 카메라를 기본으로 한다. 신하, 내관, 군졸은 정지 표식이 아니라 대기·이동·응시·군중 반응을 보인다. 접근 가능한 인물과 사료는 화면 외곽의 은은한 방향표와 공간 안의 행동으로 알려 준다.

### 위기는 UI가 아니라 공간에서 시작된다

화재, 임오군란, 갑신정변은 모달 경고창으로 시작하지 않는다. 문밖의 소란, 먼 총성, 흔들리는 등불, 바뀌는 군중의 동선, 연기와 붉은 반사광이 먼저 도착한다. 그 뒤에만 짧은 목표 문장이 나온다.

### 결정을 내리는 사람은 고종이다

회의와 교지는 얇은 반투명 카드가 아니라 어전의 자리, 장계, 지도, 어보가 놓인 탁자에서 시작한다. 문서를 읽는 행위와 결정을 내리는 행위가 공간 안의 손짓으로 연결된다.

## 시각 시스템

| 토큰 | 값 | 역할 |
| --- | --- | --- |
| 밤 목재 | `#10130F` | 바닥, UI 배경, 위기 장면의 명암 |
| 옻칠 적색 | `#6E1E1B` | 위기 유도, 왕실 상징, 선택의 결정점 |
| 등불 금빛 | `#D6A64C` | 상호작용, 따뜻한 실내광, 중요 물체 |
| 비단 청회 | `#6C8190` | 새벽·외부 안개, 중립 정보 |
| 한지 백색 | `#E8DEC6` | 읽기 본문과 사료면 |

- 본문은 `Malgun Gothic` 계열의 높은 가독성을 우선하고, 제목·연호에는 기존 시스템에서 안정적으로 렌더되는 명조 계열을 제한적으로 사용한다.
- 장면마다 한 가지 기억 요소만 강하게 쓴다. 1막은 새벽빛, 2막은 해무와 외세 함선 정보, 3막은 불, 4막은 군중, 5막은 총성과 청색 밤이다.
- 둥근 카드·과도한 그림자·상시 표시되는 점수판을 사용하지 않는다.

## 씬과 카메라

1. **탐색** — 고종 뒤·약간 위에서 따라가는 카메라. 시야를 가리는 천장과 벽은 투명화하고, 시선 높이와 속도는 안정적으로 유지한다.
2. **알현·사료** — 대화 상대와 문서를 향해 카메라가 부드럽게 접근한다. 읽기 화면은 배경을 지우지 않고 주변 조명을 낮춘다.
3. **어전회의** — 왕좌·신하·문서가 한 프레임에 들어오는 고정 구도. 선택 시 붓끝, 도장, 신하의 반응으로 피드백한다.
4. **위기** — 짧은 시네마틱 도입 뒤 조작권을 즉시 돌려준다. 강제 카메라는 방향 감각을 잃게 하지 않는 1~2초 이내로 제한한다.
5. **이동/엔딩** — 이어의 성격에 따라 카메라·조작권·동행 인물을 달리하여, 왕의 자율성이 축소되는 과정을 몸으로 느끼게 한다.

## 상호작용 설계

- `E`/탭: 가까운 인물·문서·문을 조사한다. 같은 행동 이름을 모든 화면에서 사용한다.
- 사료: 3D 장계·서책·지도에 접근해 시작한다. 읽은 뒤 사초함에 보관하며, 현행 소실 규칙을 적용한다.
- 목적 유도: 화면 중앙의 화살표 대신 바닥의 희미한 등불선, NPC의 손짓, 소리 방향과 최소형 거리 표시를 결합한다.
- 위기: 달리기, 문 열기, 변장 고르기, 인물에게 맡기기처럼 사건의 실제 조건을 행동으로 분해한다.
- 결과: 선택 직후 "정답/오답"을 표시하지 않는다. 신하의 대사, 공간 반응, 그리고 `실제로는` 기록 카드로 역사와 플레이를 분리한다.

## UI 레이어

```text
┌ 날짜·연호 ─────────────────────────────── 사초함(Q) ┐
│                                                        │
│                  3D 궁궐 / 사건 장면                  │
│                                                        │
│       [인물·문서의 공간 내 신호와 짧은 상호작용]       │
│                                                        │
└ 현재 목적 · 위기 시 남은 시간만 표시 ─────────────────┘
```

- HUD는 연호·현재 목적·사초함이라는 세 요소만 기본 노출한다.
- 위기 때만 남은 시간과 위험 방향을 추가하며, 평시에는 즉시 숨긴다.
- 대화는 인물 초상과 한지 패널을 유지하되, 화면 하단의 넓은 고정 상자 대신 인물의 위치를 존중하는 낮은 자막형 패널로 바꾼다.
- 선택은 어전회의 장면에서만 나타나며, 해금되지 않은 선택도 이유와 필요한 사료를 설명한다.

## 기술 경계

- 기존 Three.js 단일 번들, 장면·NPC·이벤트 데이터 구조를 활용한다. 새 런타임 의존성은 추가하지 않는다.
- 렌더링은 그림자 품질을 장면별로 조절하고, 화재·연기·군중은 재사용 가능한 저비용 파티클 및 인스턴싱 중심으로 구성한다.
- `prefers-reduced-motion`에서 카메라 흔들림·플래시·강한 화면 이동을 제거하고, 방향과 위기 정보는 텍스트와 색 대비로 보완한다.
- 모든 장면은 마우스, 키보드, 터치에서 끝까지 진행 가능해야 한다.

## 검증 기준

- 각 막에서 탐색, NPC 상호작용, 사료 획득, 회의 선택, 다음 막 진행을 자동 검증한다.
- 역사적 문구·연도·출처·등급은 기존 데이터 정합성 테스트를 유지하고 확장한다.
- 데스크톱 1280×720 및 태블릿 세로 화면에서 HUD·대화·선택지가 잘리지 않는다.
- 빌드된 `dist/어전.html`을 실제 브라우저로 실행해, 초기 로드·입력·위기 장면·엔딩의 콘솔 오류와 시각적 겹침을 확인한다.

## 범위 밖

- 한성 전체 오픈월드, 역사 결과의 대체 분기, 로그인·서버·멀티플레이는 만들지 않는다.
- 확인되지 않은 역사 장면을 사실처럼 추가하지 않는다. 필요한 재구성은 기존 등급 표기 방식으로 명시한다.
