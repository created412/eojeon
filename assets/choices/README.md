# 정책·사료 선택 그림

2026-10-06 사용자의 「선택지마다 그림을 만들어 힉스필드로」 요청에 따라 Higgsfield의 `gpt_image_2_5`로 생성했다. 6개 atlas의 73칸 가운데 검토용 여분 1칸을 제외한 72장을 사용한다. 네 정책판의 보기 12장과 실제 역사 4장, 네 사료판의 문항 보기 46장과 빈칸 낱말 10장이다.

`manifest.json`은 각 칸의 순서·선택지 키·생성 장면 설명, `provenance.json`은 생성 작업과 원본 URL을 보존한다. 선택의 정오값은 이미지 선택·색에 사용하지 않는다. 화면에는 모두 **재구성** 표시를 붙이며 실제 사료 지문과 출처는 `src/data/studies.js`에서 그대로 가져온다. 인물의 얼굴을 확인된 초상처럼 제시하지 않는다.

정강의 실제 역사 그림은 첫 생성에 잘못된 미국 깃발이 들어가 별도 생성한 `d-reform-actual-override.png`로 교체했다. 사용되는 개별 WebP와 내장 데이터에는 교체 그림만 들어간다.

다시 포장하려면 저장소 뿌리에서 `python tools/pack-choice-art.py`를 실행한다. 선택지별 WebP와 `src/ui/choice-art-data.js`를 만든다. 정책판의 세로 그림은 가로 카드에서 확대되어도 흐려지지 않도록 최대 480×560, 사료 보기는 최대 480×320으로 포장한다. 원본 atlas는 포장 재현을 위해 보관하고 게임에는 WebP만 내장한다.
