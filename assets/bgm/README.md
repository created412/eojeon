# 어전 — Suno 배경 음악

2026-10-05 선생님 요청: 「기존 게임에서의 bgm대신에 오프닝에서 썼던거 suno에 있으니 가져오고, 게임에 최적화된 각각 BGM SUNO에서 만들어봐.」

기존 Beneath the Bronze Bell 편집본을 전부 교체했다. 첫 화면은 **Suno 원곡이 들어 있는 V23 영상**, 게임 장면은 Suno v6에서 새로 만든 연주곡을 사용한다. V23 영상은 그대로 두며 게임 재생 시 원래 대사·음악을 포함한 연속 사운드트랙을 사용한다. 마지막 6초 영상이 돌아가도 Suno 원곡의 다음 부분이 계속 흐른다.

## 게임용 손질

10개 반복곡은 원곡 중 28~36초 길이에서 양 끝의 스펙트럼과 음량이 비슷한 구간을 찾는다. 이는 악절·박자 인식을 보증하지 않는다. 1.2초 등가전력 크로스페이드로 끝과 처음을 겹치고, 조용한 영교차 부근으로 시작점을 옮겨 코덱 경계의 클릭을 줄인다. 일회성 두 곡은 마지막에 길게 사그라진다.

모노 Opus, −20 LUFS를 목표로 음량을 맞춘다. 게임에서는 1.4초 전환, 걷기 0.32·읽기 0.17·음성 중 0.10의 음량 정책을 사용한다. 2026-10-06 추가 수정으로 척화비에도 `council`을 0.17로 연결했다. 기록 강탈·움직일 수 없는 순간·홀로 있는 짧은 장면만 BGM을 비운다. 영상 중에는 게임 BGM을 멈추고, 마지막 구간 반복 중에도 게임 BGM은 멈춰 있다. 「게임 시작」을 누르면 1막 곡이 낮게 시작한다. 별도 제목 화면을 없앴으므로 `theme.ogg`는 첫 화면에서 따로 재생하지 않는다.

화면 왼쪽 아래의 「소리 켜짐/꺼짐」으로 사료·회의·미니게임·막 마무리에서도 소리를 조절한다. 사용자의 음소거는 장면 전환 페이드와 달리 즉시 적용하며, 이미 재생 중인 막 종지·기록 상실의 짧은 음악도 함께 멈춘다. 복원된 사료 읽기·막 완료 저장은 현재 막의 낮은 음악으로 시작한다. 활동을 마치고 탐색으로 돌아올 때도 해당 막의 곡을 유지한다.

원본 MP3는 이 폴더 아래 보관하며 게임에는 편집 OGG만 base64로 넣는다. 음악 재생에는 인터넷이 필요 없다. 오프닝의 연속 사운드트랙만 `assets/video/eojeon-prologue-continuous.m4a`로 HTML 곁에 둔다. 게임 진입 때 1.4초에 걸쳐 오프닝 음량을 낮춘다.

## 다시 만들기

```sh
python tools/bgm-from-suno.py
python tools/pack-bgm.py
node build.mjs
```

`bgm-from-suno.py`는 보관한 MP3만 사용한다. Suno에 재생성을 요청하거나 다운로드하지 않는다. 이전 `bgm-from-teacher.py`는 공통 음원 편집 함수를 가져오는 용도로만 쓰며, 직접 실행하면 이전 음악으로 덮어쓰므로 실행하지 않는다.

`browser-validation.json`은 별도 제목 화면이 있던 BGM 교체 직후의 검사 기록이다. 현재 영상 진입 방식은 [최종 점검 기록](../../docs/final-validation-2026-10-05.md)을 따른다.
