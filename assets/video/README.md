# 어전 프롤로그 V23

사용자가 지정한 Codex 제작 **55초 수정본 V23**을 원본 그대로 복사했다.

- 파일: `eojeon-prologue-v23.mp4`
- 길이: 55초 / 1,320프레임 / 24fps
- 화면: 1280×720
- 용량: 25,586,417바이트
- SHA-256: `2df78f28f9dee53baac3c6a9a455c39903ed8e4a12bb424879c9a2b84eeb2ef7`
- 원본 위치: Codex 시각화 작업 `2026/09/30/01a0f23e-cb1f-7671-88e5-1b26a9185da0/eojeon-prologue-v23/`
- MP4 원본은 재편집하지 않았다. 게임에서는 화면과 소리를 분리해 아래의 연속 사운드트랙을 사용한다.

게임을 열면 별도 제목 화면 없이 **V23 영상부터 자동 재생**한다. **49초부터 오른쪽 아래에 「게임 시작」**이 나타나고, 누를 때까지 **49~55초의 마지막 6초를 반복**한다. 시작을 누르면 영상이 사라지며 1막 도입과 1막 BGM이 시작된다. 유효한 저장이 있으면 위쪽의 「이어서 하기」로 저장된 장면을 바로 연다.

「영상 건너뛰기」는 마지막 반복 구간으로 이동한다. 게임은 「게임 시작」을 눌러야 시작한다. 조작 안내를 열면 영상이 멈추고 안내를 닫으면 이전 재생 상태로 돌아온다.

AI 재구성 고지, 소리·일시 정지 단추, 안내·출처를 영상 위에 표시한다. 영상 중에는 게임 BGM이 멈춘다. 브라우저가 소리 있는 자동 재생을 차단하면 영상 위 「소리와 함께 재생」을 누를 때까지 기다린다. 무음으로 자동 전환하지 않는다. 사용자가 직접 저장해 둔 음소거 설정은 존중한다. 영상이 없거나 읽을 수 없으면 안내와 「게임 시작」을 표시하며, 버튼을 누르기 전에는 게임으로 넘어가지 않는다.

`node build.mjs`는 영상과 연속 사운드트랙을 `dist/assets/video/`로 복사한다. 루트 `어전.html`은 이 폴더의 원본을, `dist/어전.html`은 복사본을 상대 경로로 읽는다. 인터넷 연결 없이도 영상과 게임을 재생할 수 있다.

배포할 때는 게임 HTML과 **`assets/video/eojeon-prologue-v23.mp4`와 `assets/video/eojeon-prologue-continuous.m4a`를 같은 상대 경로로 함께 배포**한다. HTML만 공유하면 영상 오류 안내에서 「게임 시작」을 눌러 진행할 수 있다. HTML 본체의 크기 제한은 2026-10-06 그림·궁궐 개편에서 18MiB로 조정했다(`tests/build.test.js`).

## HTML 에 실린 판 (2026-10-06)

선생님: 「오프닝 영상을 html에 넣고」. 이제 영상과 연속 음악은 HTML 안에 base64 로 들어 있다(`src/ui/prologue-media-data.js`, `tools/pack-prologue.mjs`). HTML 하나만 건네면 오프닝이 뜬다. 곁의 `assets/video/` 파일은 더 이상 읽지 않는다.

- 실린 영상: `eojeon-prologue-v23-web.mp4` — 원본 V23 을 H.264 CRF 28 · 720p · 무음으로 다시 담은 것(4,914,349바이트). 720p 화면에서 원본과 구별되지 않는다(한 프레임을 나란히 놓고 봤다). 원본(25.6MB)을 그대로 실으면 HTML 이 50MB 를 넘고 Cloudflare Pages 의 파일 하나 상한(25MiB)을 넘는다.
- 실린 음악: `eojeon-prologue-continuous-web.m4a` — 연속 사운드트랙을 AAC 80kbps 로 다시 담은 것(1,304,946바이트).
- 원본 두 파일은 그대로 둔다. 다시 담는 명령은 `tools/pack-prologue.mjs` 머리말에 있다.

## 끊기지 않는 오프닝 음악

`eojeon-prologue-continuous.m4a`는 V23의 대사·효과·음악을 보존한 뒤 같은 Suno 원곡의 다음 부분으로 이어지는 128초 사운드트랙이다. V23 50초와 원곡 47.9초가 대응한다(상관계수 0.99978). 54~55초는 같은 시각의 원곡과 1초간 섞어 연결한다. 영상이 49초로 돌아가도 음악의 재생 위치는 바뀌지 않는다. 128초까지 기다리면 음악만 59초로 돌아가며, 124~128초에 해당 지점 직전 구간을 미리 섞어 대사가 되풀이되지 않게 했다.

영상에 있던 소리와 이 트랙이 중복되지 않도록 영상 요소 자체는 음소거한다. 사용자가 듣는 대사와 음악은 별도 오디오 요소에서 함께 재생한다. 영상 반복 때 「영상을 불러오고 있습니다」를 표시하지 않는다. 게임 시작을 누르면 오프닝 소리가 1.4초간 작아지며 게임 BGM으로 전환된다.

다시 만들기: `python tools/prologue-continuous-audio.py` → `node build.mjs`. [원본 대응·해시 기록](continuous-audio.json).
