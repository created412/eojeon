# 마당에 놓는 물건

2026-09-16 · 선생님 요청 「방 이외에도 추가할거 없나 찾아서 힉스필드로 만들어 넣어」.

방 안은 세간으로 채웠는데 마당은 나무와 회랑뿐이었고, **대본이 말하는 물건이 화면에 없었다**:
1막에서 임금은 「가마에 오른다」는데 가마가 없었고, 2막에서 학생이 비문을 쓴 척화비는 어디에도 서지 않았다.

## 만든 길

1. **기준 그림** — Higgsfield `gpt_image_2_5`, 1:1, 물건 하나만 단색 배경에. 척화비는 첫 장이 묘비 문구로 나와 비문을 못 박아 다시 그렸다.
2. **3D** — Higgsfield `image_to_3d`(Meshy), `should_texture: true`, 6000~8000 삼각형. 개당 30크레딧.
3. **줄이기** — `node tools/pack-props.mjs` → 텍스처 256 webp · meshopt · 단순화 0.015 → 개당 90~180KB, `src/render/props-data.js` 에 base64(외부 요청 0건).

놓는 자리는 `src/data/palaces.js` 의 `yard.props`, 세우는 코드는 `src/render/yard-props.js` 다.
`fromYear` 를 적으면 그 해부터 보인다 — 척화비는 1871년에 세워졌으므로 그전 장면에는 서 있지 않는다.
