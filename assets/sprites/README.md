# 인물 스프라이트 시트

2026-09-15 · 선생님 요청 「게임 디자인이 너무 단순하다 — 힉스필드로 게임에 필요한 스프라이트 시트를 모두 구해 적용」.

이전에는 몸 여섯 벌(3D 메시)을 23명이 돌려 써서 흥선대원군·최익현·김옥균이 같은 얼굴이었다.
지금은 몸이 서는 인물마다(그리고 임금 셋 — 아이·아이 평복·어른) 시트가 하나씩 있다.

## 만든 길

1. **기준 그림** — Higgsfield `gpt_image_2_5`, 16:9. 한 인물을 앞 · 비스듬 · 옆 · 뒤 넷으로 나란히, 배경은 단색 마젠타.
   인물 설명과 공통 틀은 `tools/sprite-cast.json`. 비스듬·옆은 **화면 오른쪽**을 보게 그렸다.
2. **걷기 영상** — Higgsfield **Seedance 2.0**(`seedance_2_0`, mode `fast`, 4초 · 480p · 소리 없음), 기준 그림을 `start_image` 로.
   네 인물이 제자리에서 같은 박자로 걷게 했다.
   선생님은 Seedance **2.5** 를 원했지만 2.5 는 Plus 요금제 이상에서만 열려(계정은 Basic) 선생님이 2.0 으로 바꾸기로 했다.
3. **시트로 자르기** — `python tools/sprite-sheet.py <영상.mp4> assets/sprites/<id>.webp`
   - 테두리 중앙값으로 배경 색도를 재고, 색도가 먼 곳만 인물로 남긴다(보랏빛으로 나온 영상도 있다).
   - 네 인물을 세로 빈 띠(없으면 가장 얇은 세로줄)로 가르고, 옆모습 움직임으로 한 걸음 주기를 찾는다.
   - 행 = front · three_q · side · back, 열 0 = 서 있는 자세(영상 첫 프레임), 열 1..8 = 한 걸음 주기. 칸 128×256, 발끝은 칸 아래 5px.
   - 알파는 0/255 로 자르고 가장자리 한 화소를 깎는다(분홍 윤곽선 제거 · 파일 크기 1/3).
4. **싣기** — `node tools/pack-sprites.mjs` → `src/render/sprites-data.js` (base64, 외부 요청 0건).

게임 쪽은 `src/render/anim-sprite-person.js` — 판이 카메라를 마주 보고, 인물이 향한 쪽과 카메라 각도로 행(방향)을, 걸음 시간으로 열을 고른다.

## 쓰는 크레딧

기준 그림 1장 1크레딧, 걷기 영상 1편 6크레딧(Seedance 2.0 fast 480p 4초).
